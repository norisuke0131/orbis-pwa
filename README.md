# オービス警報 PWA（個人利用）

制限速度の遵守と安全運転を支援するための、**個人利用専用**の Web アプリです。
サーバー・認証・ユーザー管理は持たず、静的ファイルだけで動作します。

> ⚠️ このアプリは速度超過を助長するものではありません。オービスの有無に関わらず、
> 制限速度を守る運転を支援するツールとして設計されています。

## セットアップ（ローカルで動かす）

位置情報 API は **HTTPS または localhost でしか動きません**。
ローカルでは簡易サーバーを立てて `localhost` で開いてください。

```bash
cd orbis-pwa
python3 -m http.server 8777
```

ブラウザで `http://localhost:8777/` を開き、「測位開始」を押します。

## iPhone のブラウザで使う

`file://` や LAN内の `http://` では GPS が動かないため、
**HTTPS の静的ホスティング**（GitHub Pages 等）に公開して、その URL を iPhone の
Safari で開きます。詳細な手順はセットアップ時のガイドを参照してください。

## 免責事項

- 本アプリが表示・警報する地点情報は、**不正確・古い・欠落している場合があります**。
  特に OpenStreetMap 由来のデータは日本国内では網羅的ではありません。
- 移動式オービス・検問は常設ではなく、「過去に取締り実績があった地点」を示すに過ぎません。
- **交通法規の遵守および安全運転の責任は、すべて運転者本人にあります。**
  本アプリの情報を理由とした一切の結果について、作者は責任を負いません。
- 運転中の端末操作は危険です。端末は必ず安全な場所に固定し、走行中は操作しないでください。

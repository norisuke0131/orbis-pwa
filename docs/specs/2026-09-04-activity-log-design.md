# 設計メモ: 地図の進行方向回転 ＋ 行動ログ＆考察

作成日: 2026-09-04 / 対象: オービス警報PWA（個人利用）

## 目的
Phase 0（地図・GPS・速度表示）に、以下2つを追加する。
1. 走行画面の地図を進行方向アップに回転させる。
2. 走行中の行動を自動記録し、日別に様々な考察（分析）ができるようにする。

## ① 地図の進行方向回転（ヘディングアップ）
- 走行画面で地図全体を回転させ、進行方向が常に画面の上になるようにする。
- 自車マーカーは画面上向きに固定（地図側が回る）。
- 実装は CSS transform による地図コンテナの回転（Leaflet 以外の CDN 依存を増やさない）。
  - 回転で四隅が欠けないよう、地図要素を画面より大きめ（対角線を包含するサイズ）にして中央配置。
  - HUD などの文字要素は水平を保つ（地図のみ回転、UIは回さない）。
- トグルで「進行方向アップ / 北アップ」を切替。既定は進行方向アップ。
- 低速/静止時は直近の有効な向きを維持（heading 不定時にガタつかせない）。

## ② 行動ログ（自動記録）
- 記録方式: 測位中は自動で常に記録（ユーザー選択）。
- 「トリップ」= 測位開始〜停止の1セッション。
- 保存点: { lat, lng, speedKmh, heading, accuracy, timestamp } を約1秒ごと。
- 保存先: IndexedDB。日付（ローカル日）ごとにトリップをまとめる。
- 元仕様の「直近N分の軌跡から地点登録」とデータ基盤を共有する。

### データモデル（IndexedDB）
- object store `trips`: { id, startedAt, endedAt, date(YYYY-MM-DD), pointCount, ...集計キャッシュ }
- object store `points`: { id, tripId, lat, lng, speedKmh, heading, accuracy, t } （tripId でインデックス）

## ③ 履歴・考察画面（分析は選択制で切替表示）
「履歴」画面 → 日付選択 → その日のトリップに対して以下を切替:
- ルート地図リプレイ: 軌跡を線表示、速度で色分け（青=遅い〜赤=速い）。再生スライダーで追跡。
- サマリー数値: 総距離 / 所要時間 / 平均速度 / 最高速度 / 停車回数・停車時間。
- 速度超過: しきい値（既定 60km/h、設定で変更）超過の回数・地点（地図マーカー）・合計時間。
- 速度の分布: 速度ヒストグラム＋時間帯別の平均速度。

## ④ プライバシーと保存
- ログは端末内（IndexedDB）のみ。サーバー送信は一切なし（移動履歴のため重要）。
- 日別削除 / 全削除。GeoJSON・CSV でエクスポート（バックアップ）。
- 設定に「N日より古いログを自動削除」（既定オフ＝全保存）。

## 画面構成の追加
- 下部に画面切替（走行 / 履歴 / 設定）を追加。元仕様の4画面構成の下地とする。

## 実装順
1. 地図回転（トグル付き）
2. IndexedDB ＋ 行動ログ自動記録（元 Phase 1 と統合）
3. 履歴・考察画面（4分析）
4. 以降、元 Phase 1 残り（地点自己登録）→ Phase 2（警報＋GPX再生）…

## 確定事項
- 速度超過しきい値: ユーザー設定の固定値（既定 60km/h）。正確な制限速度データは Phase 3 以降。
- 地図回転の既定: 進行方向アップ（トグルで北アップ）。
